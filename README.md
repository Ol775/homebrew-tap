# Homebrew tap

Casks for Ol775's macOS apps (Apple silicon and Intel).

```sh
brew install --cask Ol775/tap/claude-usage    # menu bar app for your Claude session and weekly limits (macOS 13+)
brew install --cask Ol775/tap/task-manager    # native Windows-style task manager (macOS 15+)
```

- [Claude Usage](https://github.com/Ol775/Claude-Usage)
- [Task Manager](https://github.com/Ol775/macos-task-manager)

Update with `brew upgrade --cask <name>` (both apps also update themselves).
